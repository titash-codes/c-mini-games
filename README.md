# MindCare - Odd-Even Sorting Game 🧠🎮

An interactive C-based cognitive game designed to test speed, decision-making, and accuracy by classifying numbers as Odd or Even.

## 🌟 Features
* **3 Difficulty Levels:**
  * **Easy:** Numbers from 1 to 50
  * **Medium:** Numbers from 50 to 500
  * **Hard:** Numbers from 1000 to 9999
* **Speed Bonus System:** Extra points rewarded for fast response times.
* **Performance Tracking:** Displays accuracy percentage, average response time, total score, and personal high scores.

## 🛠️ How to Run

1. Compile the program using a C compiler (e.g., GCC):
   ```bash
   gcc Odd_Even_Sorting_game.c -o odd_even_game
